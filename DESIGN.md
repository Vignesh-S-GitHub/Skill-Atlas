# SkillAtlas design

The directory is a search-first reference tool. Its visual identity uses the lines, guides, and coordinate points of an atlas. The artwork stays in the hero. The rest of the interface prioritizes reading listings and changing filters.

Dark is the initial theme. Olive-black surfaces, warm neutral text, and a single chartreuse accent in dark mode carry over to warm paper and a deeper olive accent in light mode. Inter is self-hosted. Cards use a 16px radius, restrained elevation, and repeated action placement. Line icons work alongside visible labels and named icon buttons.

On small screens filters live in a bottom sheet, the main input stays sticky, and the comparison table scrolls within its panel. Focus, selection, and verified metadata use more than color to communicate state.
